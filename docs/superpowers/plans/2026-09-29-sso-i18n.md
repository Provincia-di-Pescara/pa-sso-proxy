# i18n pagine utente (IT/EN/FR/DE/ES) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Discovery page, pagina di errore e messaggi d'errore dei backend SATOSA in 5 lingue, con lingua risolta automaticamente (browser) e selettore a tendina.

**Architecture:** Una sola fonte di traduzioni (`satosa/public/static/i18n/<lang>.json`, chiavi piatte) servita come statico alla discovery e letta dal modulo server `satosa/plugins/i18n.py` (puro Python, nessuna dipendenza SATOSA → testabile anche fuori dal container). I backend passano da testi fissi a chiavi; `handle_error` traduce nella lingua risolta. `eid-<lang>.json` generato da config-api diventa solo dati dinamici (nessun testo), 5 file.

**Tech Stack:** Python 3.12 (SATOSA fork), Jinja2, JS vanilla (ES5 come il resto di `disco.html`), FastAPI/pytest (config-api), pytest nel container satosa.

**Spec:** `docs/superpowers/specs/2026-09-24-sso-i18n-design.md`

## Global Constraints

- Lingue supportate: `it`, `en`, `fr`, `de`, `es`. Default e fallback finale: `it`. Fallback chiave a runtime: lingua → `en` → `it` → chiave stessa.
- Precedenza (server e client identica): cookie `sso_lang` → `ui_locales` della richiesta OIDC → `Accept-Language` / `navigator.languages` → `it`.
- Matching per lingua primaria: `fr-CA` → `fr`, `de-AT` → `de`, `es-419` → `es`. Valori non supportati ignorati.
- Cookie `sso_lang`: `Path=/; Max-Age=31536000; SameSite=Lax; Secure`.
- Selettore lingua: **menu a tendina** (`<select>`), opzioni con endonimi (Italiano, English, Français, Deutsch, Español), non tradotte.
- Traduzioni FR/DE/ES scritte in questa implementazione (decisione utente: rilascio diretto, nessun revisore interno). Nomi propri (SPID, CIE, eIDAS, AgID, nomi gestori) mai tradotti.
- `/verifica` e WebUI admin restano solo in italiano.
- Dettagli tecnici dinamici (messaggi validatore SAML, eccezioni, `error`/`error_description` dell'IdP CIE) non si traducono: vanno nel campo `detail` della pagina d'errore.
- Redirect OIDC d'errore al client: `error=access_denied` invariato; `error_description` = messaggio tradotto nella lingua risolta.
- Ogni nuova chiave va aggiunta in tutti e 5 i JSON (test di completezza lo impone).
- Bump versione = patch (`publiccode.yml` → `0.9.8`).
- Mai push su `main`: branch + PR, squash merge.

## Review Focus

1. **Cookie `sso_lang` manomesso** (es. `sso_lang=xx`, `sso_lang=../../etc`, header Cookie malformato) → ignorato, si passa al livello successivo; mai path traversal nel caricamento del JSON. Test: `test_resolve_lang_ignores_unsupported_cookie`, `test_resolve_lang_malformed_cookie_header`, `test_load_rejects_unknown_lang` (Task 1).
2. **`Accept-Language` con `q=0`, `*`, pesi non numerici** → `q=0` escluso, `*` ignorato, peso invalido trattato come 0 senza eccezione. Test: `test_parse_accept_language_edge_cases` (Task 1).
3. **Flusso persona giuridica + lingua**: URL discovery con sia `legal_entity=1` sia `lang=` → entrambi presenti, nessuno duplicato. Test: `test_disco_query_adds_lang_and_legal_entity` (Task 2).
4. **Traduzione con placeholder / HTML**: valore con `<strong>` in chiavi `*.html`-rese dalla discovery; stessi placeholder `{...}` in tutte le lingue. Test: `test_catalog_same_placeholders` (Task 1).
5. **Contesto senza stato OIDC o senza header** (errore prima che lo stato esista, `context=None`) → `it`, nessuna eccezione. Test: `test_resolve_lang_none_context`, `test_resolve_lang_context_without_headers` (Task 1).

```python
"""Completezza del catalogo i18n e copertura delle chiavi usate.

Gira sull'host (job `pytest` di satosa-tests.yml): nel container satosa è
montata solo /tests, quindi i sorgenti del repo non ci sono → skip.

import json
import re
from pathlib import Path

import pytest

REPO_SATOSA = Path(__file__).resolve().parents[1]
I18N_DIR = REPO_SATOSA / "public" / "static" / "i18n"
LANGS = ("it", "en", "fr", "de", "es")

pytestmark = pytest.mark.skipif(not I18N_DIR.is_dir(), reason="sorgenti repo non disponibili")

_PLACEHOLDER = re.compile(r"\{(\w+)\}")


def _catalog(lang):
    return json.loads((I18N_DIR / f"{lang}.json").read_text(encoding="utf-8"))


def test_catalog_same_keys_in_all_languages():
    ref = set(_catalog("it"))
    for lang in LANGS[1:]:
        keys = set(_catalog(lang))
        assert keys == ref, f"{lang}: mancanti={sorted(ref - keys)} extra={sorted(keys - ref)}"


def test_catalog_no_empty_values():
    for lang in LANGS:
        empty = [k for k, v in _catalog(lang).items() if not isinstance(v, str) or not v.strip()]
        assert not empty, f"{lang}: valori vuoti {empty}"


def test_catalog_same_placeholders():
    ref = _catalog("it")
    for lang in LANGS[1:]:
        cat = _catalog(lang)
        for key, value in ref.items():
            assert set(_PLACEHOLDER.findall(cat[key])) == set(_PLACEHOLDER.findall(value)), f"{lang}:{key}"


def test_catalog_html_markup_only_in_html_keys():
    for lang in LANGS:
        for key, value in _catalog(lang).items():
            if not key.endswith("_html"):
                assert "<" not in value, f"{lang}:{key} contiene markup ma non è una chiave _html"


def test_disco_keys_exist():
    html = (REPO_SATOSA / "public" / "static" / "disco.html").read_text(encoding="utf-8")
    used = set(re.findall(r'data-i18n(?:-html)?="([^"]+)"', html))
    used |= {k for _attr, k in re.findall(r'data-i18n-attr="([\w-]+):([^"]+)"', html)}
    used |= set(re.findall(r"\bt\('([\w.]+)'", html))
    assert used, "nessuna chiave trovata in disco.html"
    missing = used - set(_catalog("it"))
    assert not missing, f"chiavi usate in disco.html ma assenti: {sorted(missing)}"


def test_server_keys_exist():
    sources = [
        REPO_SATOSA / "plugins" / "spidsaml2.py",
        REPO_SATOSA / "plugins" / "cieoidc-backend" / "cieoidc.py",
        REPO_SATOSA / "plugins" / "cieoidc-endpoints" / "authorization_callback_endpoint.py",
        REPO_SATOSA / "public" / "templates" / "spid_login_error.html",
    ]
    used = set()
    for src in sources:
        used |= set(re.findall(r"""["']((?:error|common|footer)\.[\w.]+)["']""", src.read_text(encoding="utf-8")))
    assert used, "nessuna chiave trovata nei plugin"
```

```python
except ImportError:  # host: carica il file dal repo

        "i18n", Path(__file__).resolve().parents[1] / "plugins" / "i18n.py"

class _Ctx:
    def __init__(self, cookie="", accept_language=None, oidc_request=None):
        self.http_headers = {}
        if cookie:
            self.http_headers["HTTP_COOKIE"] = cookie
        if accept_language is not None:
            self.http_headers["HTTP_ACCEPT_LANGUAGE"] = accept_language
        self.cookie = cookie
        self.state = {"OIDC": {"oidc_request": oidc_request}} if oidc_request is not None else {}


def test_normalize():
    assert i18n.normalize("fr-CA") == "fr"
    assert i18n.normalize("DE_at") == "de"
    assert i18n.normalize("es-419") == "es"
    assert i18n.normalize("pt-BR") is None
    assert i18n.normalize("") is None
    assert i18n.normalize(None) is None


def test_parse_accept_language_orders_by_q():
    assert i18n.parse_accept_language("de;q=0.5, fr-CH, en;q=0.8") == ["fr", "en", "de"]


def test_parse_accept_language_edge_cases():
    assert i18n.parse_accept_language("fr;q=0, en") == ["en"]
    assert i18n.parse_accept_language("*, es") == ["es"]
    assert i18n.parse_accept_language("de;q=abc, it;q=0.1") == ["it"]
    assert i18n.parse_accept_language("en-GB, en-US") == ["en"]
    assert i18n.parse_accept_language(None) == []

    assert i18n.lang_from_cookie("a=1; sso_lang=de; b=2") == "de"
    assert i18n.lang_from_cookie("sso_lang=xx") is None
    assert i18n.lang_from_cookie(None) is None
```

```python
"""Internazionalizzazione delle pagine utente del proxy.

Fonte unica delle traduzioni: /satosa_proxy/static/i18n/<lang>.json (stessi file
serviti alla discovery page). Modulo senza dipendenze SATOSA: testabile fuori
dal container.

Precedenza lingua (identica in disco.html): cookie sso_lang → ui_locales della
richiesta OIDC → Accept-Language → it.
"""
import json
import logging
import os
import urllib.parse
from functools import lru_cache
from http.cookies import CookieError, SimpleCookie

logger = logging.getLogger(__name__)

SUPPORTED = ("it", "en", "fr", "de", "es")
DEFAULT = "it"
COOKIE_NAME = "sso_lang"
I18N_DIR = os.environ.get("SSO_I18N_DIR", "/satosa_proxy/static/i18n")


def normalize(tag):
    """Lingua primaria supportata ('fr-CA' → 'fr'), altrimenti None."""
    if not tag:
        return None
    primary = tag.strip().replace("_", "-").split("-", 1)[0].lower()
    return primary if primary in SUPPORTED else None


def parse_accept_language(header):
    """Lingue supportate da Accept-Language, per peso q decrescente, senza duplicati."""
    if not header:
        return []
    weighted = []
    for pos, part in enumerate(header.split(",")):
        tag, _, params = part.strip().partition(";")
        q = 1.0
        params = params.strip()
        if params.startswith("q="):
            try:
                q = float(params[2:])
            except ValueError:
                q = 0.0
        lang = normalize(tag)
        if lang and q > 0:
            weighted.append((-q, pos, lang))
    result = []
    for _q, _pos, lang in sorted(weighted):
        if lang not in result:
            result.append(lang)
    return result


def lang_from_cookie(cookie_header):
    if not cookie_header:
        return None
    try:
        jar = SimpleCookie()
        jar.load(cookie_header)
    except CookieError:
        return None
    morsel = jar.get(COOKIE_NAME)
    return normalize(morsel.value) if morsel else None


def ui_locales_lang(context):
    """Prima lingua supportata in ui_locales della richiesta OIDC nello stato SATOSA."""
    for v in (getattr(context, "state", None) or {}).values():
        if isinstance(v, dict) and "oidc_request" in v:
            try:
                params = urllib.parse.parse_qs(v.get("oidc_request") or "")
            except Exception:
                return None
            for tag in params.get("ui_locales", [""])[0].split():
                lang = normalize(tag)
                if lang:
                    return lang
            return None
    return None


def resolve_lang(context):
    if context is None:
        return DEFAULT
    headers = getattr(context, "http_headers", None) or {}
    cookie = getattr(context, "cookie", None) or headers.get("HTTP_COOKIE")
    lang = lang_from_cookie(cookie) or ui_locales_lang(context)
    if lang:
        return lang
    browser = parse_accept_language(headers.get("HTTP_ACCEPT_LANGUAGE"))
    return browser[0] if browser else DEFAULT


@lru_cache(maxsize=None)
def _load(lang):
    if lang not in SUPPORTED:
        return {}
    try:
        with open(os.path.join(I18N_DIR, f"{lang}.json"), encoding="utf-8") as fh:
            return json.load(fh)
    except (OSError, ValueError) as exc:
        logger.error(f"i18n: impossibile caricare {lang}.json: {exc}")
        return {}


def t(lang, key, **params):
    for candidate in (lang, "en", DEFAULT):
        value = _load(candidate).get(key)
        if value:
            return value.format(**params) if params else value
    return key


def template_vars(lang):
    return {"lang": lang, "t": lambda key, **params: t(lang, key, **params)}
```

```js
/* i18n — stessa precedenza del server (backends/i18n.py):
   cookie sso_lang → ?lang= (ui_locales del client, aggiunto da disco_query)
   → navigator.languages → it */
var SSO_LANGS = ['it', 'en', 'fr', 'de', 'es'];
var SSO_DICT = {};

function ssoNormLang(tag) {
  if (!tag) return null;
  var p = String(tag).replace('_', '-').split('-')[0].toLowerCase();
  return SSO_LANGS.indexOf(p) >= 0 ? p : null;
}

function ssoCookieLang() {
  var m = document.cookie.match(/(?:^|;\s*)sso_lang=([^;]*)/);
  return m ? ssoNormLang(decodeURIComponent(m[1])) : null;
}

function ssoResolveLang() {
  var l = ssoCookieLang() || ssoNormLang(new URLSearchParams(window.location.search).get('lang'));
  if (l) return l;
  var prefs = navigator.languages && navigator.languages.length ? navigator.languages : [navigator.language];
  for (var i = 0; i < prefs.length; i++) {
    l = ssoNormLang(prefs[i]);
    if (l) return l;
  }
  return 'it';
}

var SSO_LANG = ssoResolveLang();

function t(key, fallback) {
  return SSO_DICT[key] || fallback || key;
}

function ssoApplyI18n() {
  document.documentElement.lang = SSO_LANG;
  document.querySelectorAll('[data-i18n]').forEach(function(el) {
    var v = SSO_DICT[el.getAttribute('data-i18n')];
    if (v) el.textContent = v;
  });
  document.querySelectorAll('[data-i18n-html]').forEach(function(el) {
    var v = SSO_DICT[el.getAttribute('data-i18n-html')];
    if (v) el.innerHTML = v;  /* catalogo statico del proxy, non input utente */
  });
  document.querySelectorAll('[data-i18n-attr]').forEach(function(el) {
    var parts = el.getAttribute('data-i18n-attr').split(':');
    var v = SSO_DICT[parts[1]];
    if (v) el.setAttribute(parts[0], v);
  });
  if (SSO_ENTE_NAME) {
    var n = document.getElementById('ente-name');
    if (n) n.textContent = SSO_ENTE_NAME;
  }
  var sel = document.getElementById('sso-lang-select');
  if (sel) sel.value = SSO_LANG;
}

function ssoLoadLang(lang) {
  return fetch('/static/i18n/' + lang + '.json')
    .then(function(r) { return r.json(); })
    .then(function(d) { SSO_LANG = lang; SSO_DICT = d || {}; ssoApplyI18n(); })
    .catch(function() { ssoApplyI18n(); });
}

function ssoSetLang(lang) {
  lang = ssoNormLang(lang);
  if (!lang) return;
  document.cookie = 'sso_lang=' + lang + '; Path=/; Max-Age=31536000; SameSite=Lax; Secure';
  ssoLoadLang(lang);
}

var SSO_ENTE_NAME = '';

document.addEventListener('DOMContentLoaded', function() {
  var sel = document.getElementById('sso-lang-select');
  if (sel) {
    sel.value = SSO_LANG;
    sel.addEventListener('change', function() { ssoSetLang(sel.value); });
  }
  ssoLoadLang(SSO_LANG);
});
```
